# OpenFest 2026 Workshop "Build Your Own Cloud in Bash in 2 Hours"

How to use it:

Login to the controller host and checkout this repo in /root/cloud

Initially the repo will contain only the first commit. On each step during the
workshop a new commit will be added to the main branch. Pull the new commit
with:

```
git pull
```

, and read the changes with:

```
git show
```

Follow the instructions coming with the commit.
